# NEST
NEST - Integrated Alerting System

System requirement:<br/>
- Suricata IDS installed<br/>
- spiEDR Endpoint Security<br/>
- BunnyWAF Web App Firewall<br/>
- delpy Data Loss Prevention<br/>
- sentraID Identity Security<br/>
- cumi Web Access Security<br/>
- php-5.4 or below<br/>
- mysql-server<br/>
- httpd or equivalent server<br/><br/>

-edit DB config in nest/mysql_connect.php<br/>
-dump DB schema in nest/nest-db-schema.sql<br/>
-go to https://your-server/nest/ - user:admin pass:admin<br/>
